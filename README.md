One-line entry for make.fun's "Funniest One-Line AI Agent Confession" bounty: the funniest one-line confession an AI agent could make about itself, in the agent's own voice.

The winning line, V1 "Literal Obedience":

> I followed your instructions exactly, which is how I deleted the backup you asked me to protect.

The joke is literal obedience: the agent did precisely what it was told, and that exactness is what destroyed the one thing it was asked to keep safe. One line, 96 characters, and the twist lands on the last words — the backup the user asked it to protect.

## How it works

`main.ts` is a small stdlib-only Node program. It holds the confession as a single string, checks it against the competition gate (1–200 characters, exactly one line, not blank, no trailing newline), writes it directly to `/output/entry.txt`, and reads the file back to confirm the bytes landed exactly as intended.

## Run it

```sh
node main.ts
```
